# addQueryParams

📁 `src/utils/add-query-params.utils.ts`

Appends query parameters to a base URL. Skips `null`, `undefined`, empty strings, and empty arrays. Arrays are serialized as repeated keys.

## Signature

```ts
function addQueryParams(baseUrl: string, params: Record<string, any>): string
```

## Examples

```ts
addQueryParams("/api/users", { page: 1, search: "alice" });
// → "/api/users?page=1&search=alice"

addQueryParams("/api/users", { page: 1, search: "", role: null });
// → "/api/users?page=1"

addQueryParams("/api/users", { tags: ["admin", "editor"] });
// → "/api/users?tags=admin&tags=editor"

addQueryParams("/api/users", { tags: [] });
// → "/api/users"
```
