# Infinite Query Utils

📁 `src/utils/infiniteQueryUtils.ts`

## getNextPageParam

Standard `getNextPageParam` function for `useInfiniteQuery`. Returns the next page number or `undefined` when there are no more pages.

```ts
function getNextPageParam(lastPage: { pagination: IPagination }): number | undefined
```

## transformInfiniteData

Flattens all pages of an infinite query result into a single array.

```ts
function transformInfiniteData<TData, TKey extends string>(
  data: InfiniteData<...> | undefined,
  key: TKey
): TData[]
```

## Usage

```tsx
const query = useInfiniteQuery({
  queryKey: ["posts"],
  queryFn: ({ pageParam = 1 }) => fetchPosts({ page: pageParam }),
  getNextPageParam,
  initialPageParam: 1,
});

const posts = transformInfiniteData(query.data, "posts");
// → Post[] (all pages flattened)
```
