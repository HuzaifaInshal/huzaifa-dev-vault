# handleMutationError Utils

📁 `src/utils/handleMutationError.ts`

Centralized Axios mutation error handling. Extracts a readable message from any `AxiosError` or `Error`.

## handleMutationError

Dismisses existing toasts and shows an error toast with the extracted message.

```ts
function handleMutationError(error: Error | AxiosError): void
```

## returnMutationError

Returns the extracted error message as a string without showing a toast.

```ts
function returnMutationError(error: Error | AxiosError): string
```

## Message Extraction Priority

1. `error.response.data.message` as a plain string
2. NestJS validation array → joins all constraint messages
3. `error.message`
4. `"An unexpected error occurred"`

## Usage

```ts
// Toast-based — pass directly as onError
const mutation = useMutation({ mutationFn: createUser, onError: handleMutationError });

// String-based — set form error without toast
const mutation2 = useMutation({
  mutationFn: createUser,
  onError: (error) => setFormError(returnMutationError(error)),
});
```
