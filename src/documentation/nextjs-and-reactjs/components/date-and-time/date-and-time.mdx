# Date & Time Components

All date and time picker components. Each is a Radix `DropdownMenu`-based dropdown with year/month/date drill-down, `moment` formatting, and a clear button. Time pickers auto-detect 12/24-hour format from the system locale.

---

## DateSelector

📁 `src/components/ui/DateSelector.tsx`

Single date picker with year → month → date drill-down.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `value` | `Date` | — | Selected date |
| `setValue` | `(date: Date) => void` | — | Change handler |
| `placeholder` | `string` | `"Select Date"` | Trigger placeholder |
| `trigger` | `React.ReactNode` | — | Custom trigger element |
| `disabledDates` | `Date[]` | — | Dates to disable |
| `minDate` | `Date` | — | Minimum selectable date |
| `maxDate` | `Date` | — | Maximum selectable date |
| `hideTrigger` | `boolean` | — | Hide the default trigger |
| `open` / `onOpenChange` | `boolean / fn` | — | Controlled open state |
