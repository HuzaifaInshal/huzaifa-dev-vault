# Dropdowns & Selects

---

## Dropdown

📁 `src/components/ui/Dropdown.tsx`

A Radix `DropdownMenu` that accepts any trigger via `children` and renders a list of items with ripple animations. Wraps `LabelContainer` for optional label/error.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `children` | `React.ReactNode` | — | Trigger element |
| `items` | `DropdownItem[]` | `[]` | Menu items |
| `label` | `string` | — | Label above the trigger |
| `error` | `string` | — | Error message below |
| `open` / `onOpenChange` | `boolean / fn` | — | Controlled open state |
| `contentClassName` | `string` | — | Extra classes for the menu panel |
| `required` | `boolean` | — | Required asterisk on label |

**DropdownItem shape:** `{ value: string; label: ReactNode; disabled?: boolean; onClick?: (value: string) => void }`

## Select

📁 `src/components/ui/Select.tsx`

A Radix `Select` with label, error, start/end icon slots, ripple animations, and consistent input styling. Wraps `LabelContainer`.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `options` | `SelectOption[]` | — | List of options |
| `value` | `string` | — | Controlled value |
| `setValue` | `(value: string) => void` | — | Shorthand change handler |
| `onValueChange` | `(value: string) => void` | — | Radix change handler |
| `placeholder` | `string` | `"Select an option"` | Placeholder text |
| `label` | `string` | — | Label above the select |
| `error` | `string` | — | Error message below |
| `startIcon` / `endIcon` | `React.ReactNode` | — | Icon slots |
| `disabled` / `required` | `boolean` | — | — |
| `triggerClassName` / `contentClassName` | `string` | — | Style overrides |

**SelectOption shape:** `{ value: string; label: ReactNode; disabled?: boolean }`
