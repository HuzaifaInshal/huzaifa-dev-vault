# Tables

Composable table primitives with consistent border, background, and spacing. The root `Table` wraps in a scrollable container automatically.

📁 `src/components/ui/Tables.tsx`

## Components

| Component | Element | Description |
|-----------|---------|-------------|
| `Table` | `<table>` | Root — overflow scroll wrapper |
| `TableHeader` | `<thead>` | Header with secondary background |
| `TableBody` | `<tbody>` | Body rows |
| `TableRow` | `<tr>` | Row with bottom border |
| `TableHead` | `<th>` | Header cell |
| `TableCell` | `<td>` | Data cell |

All components forward native HTML props and accept a `className` override.
