# useInfinite

📁 `src/hooks/useInfinite.ts`

Wraps a TanStack Query `useQuery` result to accumulate paginated data across page increments. Resets the accumulated list when `page` goes back to `1`.

## Signature

```ts
function useInfinite<TData, TKey extends string>(
  query: UseQueryResult<WithPagination<TData, TKey>, Error | AxiosError>,
  key: TKey,
  page: number
)
```

## Parameters

| Param | Type | Description |
|-------|------|-------------|
| `query` | `UseQueryResult` | A TanStack Query result whose data has `pagination` and a keyed array |
| `key` | `TKey` | The key in the response that holds the array (e.g. `"users"`) |
| `page` | `number` | Current page — reset to `1` to clear accumulated data |

## Returns

Spreads all `UseQueryResult` fields plus:

| Key | Type | Description |
|-----|------|-------------|
| `allData` | `TData[]` | Accumulated items across all loaded pages |
| `hasMore` | `boolean` | `true` if `pagination.nextPage` exists |

## Expected API Response Shape

```ts
{
  pagination: { nextPage: number | null };
  [key]: TData[];
}
```

## Usage

```tsx
const [page, setPage] = useState(1);

const query = useQuery({
  queryKey: ["users", page],
  queryFn: () => fetchUsers({ page }),
});

const { allData: users, hasMore, isLoading } = useInfinite(query, "users", page);

return (
  <>
    {users.map((u) => <div key={u.id}>{u.name}</div>)}
    {hasMore && (
      <button onClick={() => setPage((p) => p + 1)} disabled={isLoading}>
        Load More
      </button>
    )}
  </>
);
```
